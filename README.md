# 👋 hello-pr

**プルリクエスト(PR)を、気軽に・何度でも練習できる場所です。**

失敗しても大丈夫。ここは壊しても誰も困らない、あなた専用の練習場です。

---

## 🎯 このリポジトリでできること

- ブランチを切って、変更して、PR を出す ― という一連の流れを体で覚える
- レビュー・コメント・修正・マージを実際に試してみる
- コンフリクト(競合)をわざと起こして、解消の仕方を学ぶ

## 🚀 PR の基本の流れ

```bash
# 1. main を最新にする
git switch main
git pull

# 2. 作業用のブランチを切る
git switch -c my-first-change

# 3. ファイルを編集して、コミットする
git add README.md
git commit -m "README を更新"

# 4. GitHub に push する
git push -u origin my-first-change

# 5. PR を作る
gh pr create
```

あとは GitHub の画面で差分を確認し、「Merge pull request」を押せば完了です 🎉

## 💡 練習のアイデア

| レベル | お題 |
| --- | --- |
| 🌱 はじめて | この README の誤字を直す、絵文字を1つ足す |
| 🌿 なれてきた | PR にコメントをもらい、追加コミットで修正する |
| 🌳 ちょっと上級 | 2つの PR で同じ行を変えて、コンフリクトを解消する |

## 📌 ちいさなルール

1. `main` には直接 push しない ― 変更は必ず PR から
2. 1つの PR には1つの目的だけ
3. PR のタイトルは「何をしたか」がひと目でわかるように
